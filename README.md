# পঞ্চম শ্রেণি ইংরেজি পাঠশালা (Class 5 English Bangla)

> **English for Today (Class Five) — National Curriculum and Textbook Board (NCTB) ২০২৬ নতুন শিক্ষাক্রমের পূর্ণাঙ্গ ইন্টারঅ্যাক্টিভ সমাধান, অডিও উচ্চারণ ও স্মার্ট এআই শিক্ষক।**

---

## 🌟 প্রধান বৈশিষ্ট্যসমূহ (Key Features)

- 📖 **সম্পূর্ণ ২০টি ইউনিট**: নতুন NCTB ২০২৬ বইয়ের ১ থেকে ২০ পর্যন্ত প্রতিটি অধ্যায়ের মূল পাঠ, সংলাপ এবং প্রশ্নের পূর্ণাঙ্গ সমাধান।
- 🔊 **আন্তর্জাতিক অডিও সঠিক উচ্চারণ**: প্রতিটি বাক্য, সংলাপ ও শব্দের পাশে স্পিকার আইকন—ক্লিক করলেই নেটিভ ইংলিশ ভয়েসে সঠিক উচ্চারণ শোনা যায় (স্বাভাবিক ও ধীর গতির নিয়ন্ত্রণসহ)।
- 🇧🇩 **দ্বিভাষিক ইন্টারফেস ও অনুবাদ**: প্রতি লাইনের সাথে সহজ বাংলা অর্থ ও প্রেক্ষাপট বোঝার সুবিধা, এক ক্লিকেই বাংলা অনুবাদ দেখা বা লুকানোর অপশন।
- 📚 **সমৃদ্ধ শব্দভাণ্ডার (Vocabulary Bank)**: প্রতিটি অধ্যায়ের গুরুত্বপূর্ণ শব্দ, আন্তর্জাতিক ফোনেটিক্স (IPA), পদ (Part of Speech), বাংলা অর্থ এবং উদাহরণ বাক্য।
- 🃏 **ইন্টারঅ্যাক্টিভ ফ্ল্যাশ কার্ড (Flashcard Mode)**: কার্ড উল্টে নিজেই নিজের শব্দার্থ যাচাইয়ের রোমাঞ্চকর সুবিধা।
- ✍️ **ব্যাকরণ সহায়িকা (Grammar Hub)**: সিলেবল স্ট্রেস, কালেক্টিভ নাউন, মোডাল ভার্ব, চিঠি ও ইমেইল লেখার নিয়ম, টেন্স ও ডিগ্রি অফ কম্প্যারিজন।
- 🎯 **অনুশীলন ল্যাব ও কুইজ (Practice & Quiz Lab)**: অধ্যায়ভিত্তিক বহুনির্বাচনী প্রশ্ন (MCQ), তাত্ক্ষণিক ফলাফল ও কনফেটি উদযাপন।
- 🤖 **ইংলিশ বন্ধু (Smart AI English Tutor)**: Groq Llama 3.3 চালিত এআই শিক্ষক, যেকোনো ইংরেজি প্রশ্ন বা বাক্য রচনায় তাত্ক্ষণিক সহায়তা।

## 🚀 লোকাল সেটআপ ও রান (Local Development)

```bash
# ডিপেন্ডেন্সি ইন্সটল করুন
npm install

# ডেভেলপমেন্ট সার্ভার চালু করুন
npm run dev

# প্রোডাকশন বিল্ড তৈরি করুন
npm run build

# প্রিভিউ দেখুন
npm run preview
```

## 🛠️ ব্যবহৃত প্রযুক্তিসমূহ (Tech Stack)

- **Frontend**: React 19 + TypeScript + Vite
- **Styling**: Tailwind CSS + Lucide React Icons
- **Audio Synthesis**: Web Speech API (`SpeechSynthesisUtterance`)
- **Interactive UI**: Canvas Confetti
- **AI Integration**: Groq API (Llama 3.3 / Llama 3.1)
- **Analytics**: Google Analytics (GA4) & Google Tag Manager (GTM)
